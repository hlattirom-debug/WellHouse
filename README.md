# WellHouse

ชุดแบบบ้านเดี่ยวระดับ Design Development ที่ออกแบบโดยมีเจตนาตามเกณฑ์ **WELL for Residential** (IWBI) โดย H3A Design and Build / X-UNIT Architecture Lab

> แบบระดับ design development ต้องให้สถาปนิกและวิศวกรผู้ได้รับใบอนุญาตตรวจสอบและลงนามก่อนยื่นขออนุญาต
> สถานะ WELL ในแบบเป็น "เจตนาการออกแบบ" ไม่ใช่คะแนนรับรอง

## โปรเจกต์

| โฟลเดอร์ | ที่ดิน | ชั้น | แนวคิด | เอกสาร |
|---|---|---|---|---|
| `WELL-GBEACH-30x30/` | 30 x 30 ม. (225 ตร.ว.) ถนนทิศเหนือ | 4 | แท่งบนเสาลอย + แกนบันไดทรงกระบอกอิฐ + ผนังอิฐโปร่ง (ตีความจาก G-Beach Residence, B+D+M Architetti) | PDF A2 12 แผ่น + DXF |
| `WELL-KILN-30x30/` | 30 x 30 ม. (225 ตร.ว.) ถนนทิศเหนือ | 4 | บ้านเตาเผา: โดมอิฐ + ปล่องอิฐ + หลังคาโค้งดินเผา (ตีความจาก Intrinsic, Chain10) | PDF A2 12 แผ่น + DXF |
| `WELL-GENWEAVE-40x40-v3/` | 40 x 40 ม. (400 ตร.ว.) ถนนทิศเหนือ | 3 | GENWEAVE: ลำต้น + กิ่ง (TRUNK + BRANCH) รอบคอร์ต 2 แห่ง | PDF A2 11 แผ่น + DXF |

แต่ละโฟลเดอร์มี

- `*-drawings.pdf` ชุดแบบ A2 (ผังบริเวณ, ผังพื้นทุกชั้น, แปลนหลังคา, รูปด้าน, รูปตัด, ตารางช่องเปิด, ตารางกฎหมาย, WELL)
- `*-CAD.dxf` แบบ CAD ขนาดจริง (หน่วย มม.)
- `*-geo.json` โมเดลกล่อง 3D ที่ใช้สร้างรูปด้าน/รูปตัดและโมเดล Blender
- `*_blender.py` สคริปต์สร้างโมเดลใน Blender (อ่าน geo JSON)
- `renders/` ภาพจากโมเดล Blender (EEVEE)
- `src/` โค้ด Python ที่สร้างแบบทั้งชุด (ezdxf + matplotlib + shapely)

## สร้างแบบใหม่จากโค้ด

```bash
pip install ezdxf matplotlib shapely numpy pillow
cd WELL-GBEACH-30x30/src
python verify4.py          # ตรวจกฎกระทรวง/เกณฑ์ภายใน/WELL
python model4.py           # สร้าง gb4_model.json
python render4.py --dxf    # PDF + DXF
```

ข้อจำกัดของโค้ด: path ในโค้ดชี้ไปยังโฟลเดอร์ทำงานเดิม (`/mnt/user-data/...`) ต้องแก้ path ของ block DXF (ชุด NACK HOUSE ไม่ได้รวมใน repo), ภาพเรนเดอร์ และฟอนต์ไทย (TLWG Loma) ก่อนรัน

## ข้อจำกัดที่ต้องตรวจก่อนใช้งานจริง

- ความกว้างถนนเป็นค่าสมมติ (8.00 ม.) และยังไม่ได้ตรวจผังเมืองรวม/ข้อบัญญัติท้องถิ่น
- GBEACH: ยอดทรงกระบอก +14.85 ม. ต่ำกว่า 15.00 ม. เพียง 0.15 ม.; บันไดหนีไฟห่างเขต 3.00 ม. พอดี; ทางลาด 1:12 ยังไม่เขียน
- รายละเอียดเพิ่มเติมอยู่ในแผ่น A-01 (รายงานข้อจำกัด) ของแต่ละชุดแบบ
