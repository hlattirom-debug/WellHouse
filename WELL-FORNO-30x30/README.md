# WELL-FORNO 30x30 — บ้านโครงไม้ภายนอก

บ้านเดี่ยว 4 ชั้น ที่ดิน 30 x 30 ม. (225 ตร.ว.) ถนนทิศเหนือ (ความกว้างสมมติ 8.00 ม.)
โปรแกรม ARCHISPACE 6 ต.ค. 2569 (NUA 785 / GFA 984.70 ตร.ม.) · เจตนาตามเกณฑ์ WELL for Residential

## แนวคิด (การตีความของผู้ออกแบบ ไม่ใช่คำอธิบายของสถาปนิกต้นแบบ)

ตีความจาก FORNO (Gruppo FON Architetti, Treviso อิตาลี, 2025) ซึ่งเป็นอาคารเบเกอรี่/ร้านค้า/พื้นที่ชุมชนชั้นเดียว ไม่ใช่บ้าน

- แท่งอาคาร 23.00 x 13.00 ม. โครงหลัก ค.ส.ล. + โครงไม้ glulam ภายนอกทุกชั้น (9 เฟรม @2.875 ม. ทิศใต้ + ค้ำเอียงรับชายคา, เสา 6 ต้นหน้าโรงรถ)
- หลังคาจั่วไม่สมมาตรคลุมทั้งแท่ง: ลาดใต้ 40% ชายคา 3.00 ม., ลาดเหนือ 25%, สัน +14.95, แนวผนัง +12.95
- โถงไม้ "Forno hall" กว้าง 3.00 ม. โปร่ง 4 ชั้นถึงช่องแสงสันหลังคา มีสะพานไม้ข้ามชั้น 2-4
- ระเบียงไม้ยาว 23 ม. ทิศใต้ทุกชั้น + ผนังกระจกเต็มบาน · หน้าจั่วระแนงไม้ทแยง · คอร์ตแสงหัวท้าย
- piazza ใต้ชายคา + ศาลาริมสระ + เตาอบฟืน · PV 38 แผง (~20.9 kWp) บนลาดใต้

## ไฟล์

- `WELL-FORNO-30x30-drawings.pdf` ชุดแบบ A2 12 แผ่น (ผังบริเวณ ผังพื้น 4 ชั้น แปลนหลังคา รูปด้าน 4 ด้าน รูปตัด 2 รูป ตาราง)
- `WELL-FORNO-30x30-CAD.dxf` แบบ CAD ขนาดจริง (มม.)
- `WELL-FORNO-30x30-geo.json` + `well_forno_30x30_blender.py` สร้างโมเดล Blender (`WELL-FORNO-30x30-model.blend`)
- `renders/` ภาพจากโมเดล Blender
- `src/` โค้ด Python (frame6 / plan6 / walls6 / draw6 / furn6 / model6 / proj6 / site6 / verify6 / render6)

## ข้อจำกัดหลัก

- โครงไม้ไม่ใช่โครงสร้างหลัก (บ้าน 4 ชั้นใช้ ค.ส.ล.); โครงหลังคาไม้ต้องตรวจอัตราทนไฟ
- GFA 1,200.28 ตร.ม. (+21.9%) — ส่วนเกินเป็นลอจเจีย/ระเบียงชั้น 3-4
- สันหลังคา +14.95 ต่ำกว่า 15.00 แค่ 0.05 ม.; ชั้น 4 โปร่ง 2.60 ม. พอดีที่ผนังชายคา; ลิฟต์ต้องเป็นรุ่น overhead <= 2.60 ม.
- โถงโปร่ง 4 ชั้นต้องมีระบบตรวจจับ/ระบายควัน; ทางเข้าบันไดหนีไฟชั้น 2 และ 4 ผ่านห้อง
