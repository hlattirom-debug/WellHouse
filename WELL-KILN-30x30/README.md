# WELL-KILN 30x30 — "บ้านเตาเผา"

บ้านเดี่ยว 4 ชั้น ที่ดิน 30 x 30 ม. (225 ตร.ว.) ถนนทิศเหนือ (ความกว้างสมมติ 8.00 ม.)
โปรแกรม ARCHISPACE 6 ต.ค. 2569 (NUA 785 / GFA 984.70 ตร.ม.) · เจตนาตามเกณฑ์ WELL for Residential

## แนวคิด (การตีความของผู้ออกแบบ ไม่ใช่คำอธิบายของสถาปนิกต้นแบบ)

ตีความจาก Intrinsic (Chain10 Architecture & Interior Design Institute) ซึ่งเป็นงานตกแต่งภายในโชว์รูมสุขภัณฑ์ที่เกาสง ไต้หวัน ไม่ใช่บ้าน

- โดมอิฐ "เตาเผา" Ø5.60 ม. ยอด +6.25 เป็นโถงต้อนรับ มีช่องแสง oculus
- หอบันได + ลิฟต์อิฐ ("ปล่อง") สูง +14.85 มีช่องแสงหลังคาและเกล็ดระบายอากาศ
- ห้องนั่งเล่นครอบครัวชั้น 4 ใต้หลังคาโค้งดินเผา มีหน้าต่างโค้ง "ปากเตา" ทิศใต้
- ฐานอิฐชั้น 1 + ผนังปูนฉาบ calce ชั้น 2-4 · ครีบดินเผาทิศตะวันตก · ฉากกระจกตัว U ที่ลอจเจียชั้น 3
- พื้นโมเสกเศษเซรามิกรีไซเคิลแนวเส้นโค้งที่โถงและลานใต้ถุน

## ไฟล์

- `WELL-KILN-30x30-drawings.pdf` ชุดแบบ A2 12 แผ่น
- `WELL-KILN-30x30-CAD.dxf` แบบ CAD ขนาดจริง (มม.)
- `WELL-KILN-30x30-geo.json` + `well_kiln_30x30_blender.py` สร้างโมเดล Blender
- `renders/` ภาพจากโมเดล Blender
- `src/` โค้ด Python (frame5 / plan5 / walls5 / draw5 / furn5 / model5 / proj5 / site5 / verify5 / render5)

> แบบระดับ design development ต้องให้สถาปนิกและวิศวกรผู้ได้รับใบอนุญาตตรวจสอบและลงนามก่อนยื่นขออนุญาต
