# WELL-RIVERA 30x30 — บ้านเกลียวคู่รอบคอร์ต

บ้านเดี่ยว 4 ชั้น ที่ดิน 30 x 30 ม. (225 ตร.ว.) ถนนทิศเหนือ (ความกว้างสมมติ 8.00 ม.)
โปรแกรม ARCHISPACE 6 ต.ค. 2569 (NUA 785 / GFA 984.70 ตร.ม.) · เจตนาตามเกณฑ์ WELL for Residential

## แนวคิด (การตีความของผู้ออกแบบ ไม่ใช่คำอธิบายของสถาปนิกต้นแบบ)

ตีความจาก Rivera Paradise (AtelierM, Buenos Aires 2026) ซึ่งเป็นบ้าน 200 ตร.ม. บนที่ดินแคบในเขตอนุรักษ์

- วงแหวน 4 ปีก 22.00 x 20.50 ม. รอบคอร์ตกลาง 10.00 x 7.00 ม. เปิดฟ้า (พื้นอิฐ สระสะท้อนเงา ต้นไม้)
- ปีกลดชั้นแบบเกลียว: W 1 ชั้น -> N 2 ชั้น -> E 3 ชั้น -> S 4 ชั้น หลังคาทุกปีกเป็นสวน
- บันไดเกลียวคู่: เกลียวใน (บันไดหลัก + ลิฟต์ปีกใต้) + เกลียวนอก H1-H4 ไต่สวนหลังคา +3.65 / +6.85 / +10.05 / +13.25 (ใช้เป็นทางหนีไฟ)
- ผนังอิฐโชว์ด้านข้าง + สวนแนวตั้ง · เพดานโค้งอิฐเหนือโถงต้อนรับสูง 2 ชั้น · รางต้นไม้ห้อยทุกขอบพื้น

## ไฟล์

- `WELL-RIVERA-30x30-drawings.pdf` ชุดแบบ A2 12 แผ่น · `WELL-RIVERA-30x30-CAD.dxf` แบบ CAD ขนาดจริง (มม.)
- `WELL-RIVERA-30x30-geo.json` + `well_rivera_30x30_blender.py` สร้างโมเดล Blender (`WELL-RIVERA-30x30-model.blend`) · `renders/`
- `src/` โค้ด Python (frame7 … render7)

## ข้อจำกัดหลัก

- GFA 1,098 ตร.ม. (+11.5%) — ส่วนเกินคือห้องฟิตเนส/ห้องเครื่องสระชั้น 1 และลอจเจียชั้น 3
- ครัวโชว์ -29%, ระเบียง Master -27%, ซักรีด -25% · โถงต้อนรับ +50%, แม่บ้าน +43%
- ทางหนีไฟผ่านสวนหลังคาและคอร์ต ต้องยืนยันข้อ 27 กับสำนักงานเขต
- สวนหลังคา 339 ตร.ม. น้ำหนักดิน + กันซึม; คอร์ตปิดล้อมต้องมีระบบระบายน้ำของตัวเอง
